Lighthouse Café ☕🌆  
Welcome to Lighthouse Café — a sleek, premium-dining restaurant website built with pure HTML, CSS, and JavaScript.  

This project was inspired by the real Lighthouse Café located in Patna, Bihar — a rooftop dining experience with panoramic views and carefully curated dishes. I used this build to sharpen my front-end skills, experiment with layouts, and learn how to present a brand online with elegance and clarity.  

🌟 Tech Used  
- HTML5  
- CSS3  
- JavaScript (vanilla)  
- Google Fonts  

 🍀Features Implemented  
- Fully responsive design for desktop, tablet, and mobile  
- Smooth scrolling navigation  
- Hero section with restaurant tagline and call-to-action  
- Menu highlights section with featured dishes  
- Customer testimonials section  
- Contact details and booking call-to-action  

🪶 Features I’m Planning to Add  
- Interactive table reservation form (frontend only for now)  
- Light/Dark theme toggle  
- Animated menu transitions  
- Lazy-loading images for better performance
